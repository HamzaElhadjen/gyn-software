# Software Gyn - Application de Gestion de Clinique Medicale

Une application de bureau developpee en Python avec PyQt5, concue pour simplifier la gestion quotidienne d'un cabinet medical ou d'une clinique. 

Note de confidentialite : 
Ce depot a pour but de presenter mon travail de developpement (portfolio). Le code source de l'application reste prive afin de proteger la propriete intellectuelle du logiciel. Les informations ci-dessous decrivent l'architecture et les fonctionnalites que j'ai implementees.

Fonctionnalites developpees :
- Gestion des dossiers patients : Creation, modification et archivage securise des historiques medicaux.
- Planification des rendez-vous : Systeme de calendrier pour organiser les consultations.
- Acces multi-utilisateurs : Gestion des permissions securisees (medecin, secretaire).
- Suivi financier : Historique des paiements, gestion de la comptabilite de base en DZD et exportation Excel/PDF.
- Generation de rapports PDF : Creation automatique et impression d'ordonnances et de bilans.

Technologies maitrisees sur ce projet :
- Langage de programmation : Python 3
- Interface Graphique (GUI) : PyQt5
- Base de donnees : SQLite
- Generation de documents : Outils de creation PDF
